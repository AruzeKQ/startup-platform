# StartupMatch 🚀 - Nền tảng kết nối Startup và Nhân tài

Đây là một dự án học tập (Study Project) nhằm mục đích thực hành và củng cố kiến thức xây dựng một ứng dụng Web Fullstack. 

Dự án cung cấp không gian kết nối giữa các Startup (cần tìm người cộng tác/nhân sự) và các Ứng viên (mong muốn tìm kiếm dự án khởi nghiệp tiềm năng để tham gia).

## 💻 Công nghệ sử dụng

Dự án được xây dựng dựa trên kiến trúc Client-Server với các công nghệ chính:

### Frontend
- **Framework:** ReactJS (Vite)
- **Styling:** Tailwind CSS v4
- **Routing:** React Router DOM
- **Mô hình:** Feature-based architecture

### Backend (Đang phát triển)
- **Runtime:** Node.js
- **Framework:** Express.js (hoặc framework tương đương)
- **Database:** (Cập nhật sau)

## ✨ Các tính năng chính (Dự kiến)
- **Dành cho Khách/Ứng viên:**
  - Xem danh sách các dự án tuyển dụng từ Startup.
  - Tìm kiếm và lọc dự án theo kỹ năng, địa điểm.
  - Gửi hồ sơ ứng tuyển (CV, Cover Letter).
- **Dành cho Startup:**
  - Đăng ký/Đăng nhập tài khoản hồ sơ công ty.
  - Đăng tải thông tin dự án cần tuyển dụng.
  - Quản lý và duyệt hồ sơ ứng viên.
